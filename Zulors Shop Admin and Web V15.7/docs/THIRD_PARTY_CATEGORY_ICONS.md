# Third-Party Category Icons

Zulors root category icons are generated from selected SVGs in the official Lucide icon set and then wrapped into custom Zulors category badges.

Source:
- Repository: https://github.com/lucide-icons/lucide
- Icons: https://lucide.dev
- License: ISC

Notes:
- We use category-matching generic icons, not third-party marketplace brand logos.
- The generated files are written to `storage/app/public/category/` by `scripts/apply_root_category_icons.php`.
